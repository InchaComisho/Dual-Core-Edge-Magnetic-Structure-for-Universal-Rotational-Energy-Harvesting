# グローバル普及シナリオ・シミュレーション
## 汎用回転エネルギー回収のためのデュアルコア・エッジ磁気構造

[English Version](global-adoption-scenario.md)

---

## 1. 目的

この文書は、デュアルコア・エッジ磁気構造のオープンな発電機アーキテクチャのための、**グローバル普及シナリオ・シミュレーター**を説明します。

このシミュレーターは、このオープンな発電機の構想が検証され、大規模に製造され、2026〜2050年の間に複数の部門で広く普及した**場合に**、世界の分散型エネルギー供給がどう変わりうるかを推計します。

これは、起こることを予測するのではなく、起こりうる結果の幅を探るために設計された**シナリオモデル**です。すべての数値は、ハードウェアの実測性能ではなく、例示的な仮定から導かれています。

---

## 2. シミュレートするもの

このシミュレーターは、5つの展開部門をモデル化します。

1. **都市の排水と建物内の水の流れ** — 配管、排水路、建物の水系統に組み込まれた小型ユニット
2. **農業用の灌漑と小規模な水路** — 灌漑水路や小規模な水インフラに置かれたユニット
3. **小河川とマイクロ水力の地点** — 自然の流れがあるマイクロ水力の地点に置かれたユニット
4. **分散型の垂直軸風力設備** — 都市、郊外、農村に設置される小型の垂直軸風車
5. **沿岸の潮汐・波力補助の回転システム** — 潮汐と波による回転を捉える海洋ユニット

それぞれの部門と、2026年から2050年までの各年について、このシミュレーターは次を推計します。

- 累積の設置ユニット数
- 設備容量（GW）
- 年間の発電量（TWh）
- 回避された化石燃料電力の相当量（TWh）
- 回避されたCO2排出量（Mt CO2）
- 世界の電力需要に占める割合（%）
- 設備利用率とユニット出力の仮定に対する感度

保守的な地域パイロットから、ストレステストの上限までに及ぶ、5つのシナリオをモデル化しています。

---

## 3. 主張していないこと

このシミュレーターは、次のことを主張**しません**。

- デュアルコア・エッジ磁気構造が、物理的に製作され、検証されている
- 性能、効率、出力が保証されている
- フリーエネルギー、あるいは永久機関である
- 出力エネルギーが、入力の機械的エネルギーから損失を引いたものを超えうる
- これらのシナリオが起こる、あるいは起こりやすい
- この技術が、既存のエネルギーシステムに自動的に取って代わる
- プロトタイプの検証なしに、特定の展開目標が現実的である
- 仮定した効率係数が、実測されている
- いずれかのシナリオで、エネルギー保存則が破られている

すべてのパラメータは例示的なものです。このシミュレーターは、エネルギー保存則を明示的に強制します。出力は、利用可能な機械的入力エネルギーから損失を引いたものに制限されます。

## 4. 部門の定義

### 部門1：都市の排水と建物内の水の流れ

建物と都市インフラは、排水システム、中水の回路、空調の冷却ループ、屋上の雨水システムの中に、絶えず低流量の水の動きを生み出しています。これらの流れに組み込まれた極めて小さな回転式発電機は、補助的な電力を回収できるかもしれません。想定するユニット出力の初期値は0.5 kWで、きわめて小さいものです。主な価値は、ユニットあたりの出力ではなく、大規模に展開したときの総量にあります。

### 部門2：農業用の灌漑と小規模な水路

灌漑水路は、世界の農地に絶えず水の流れを供給しています。取水口や分配地点にある小型の発電機は、灌漑の機能を妨げることなく、既存の水の動きからエネルギーを回収できるかもしれません。想定するユニット出力の初期値は2 kWです。農業環境での保守は、都市部よりも難しいと想定しています。

### 部門3：小河川とマイクロ水力の地点

マイクロ水力は、モデル化した部門の中で最も成熟しており、既存の商用の事例があります。デュアルコア・エッジの設計は、製造コストを下げ、設置を簡素化できる可能性があります。ユニット出力の初期値は10 kW、設備利用率は0.42です（季節による流量の変動を反映）。この部門は、5つの中でユニットあたりのエネルギー密度が最も高くなっています。

### 部門4：分散型の垂直軸風力

垂直軸風車は、低い高さ、全方向、都市の風環境に適しています。設備利用率の初期値は0.25で、理想的でない条件での、現実の垂直軸風車の性能を反映しています。ユニット出力は5 kWです。この部門は、地域の風況と立地の選定に最も敏感です。

### 部門5：沿岸の潮汐・波力補助

海洋環境は、持続的な潮汐と波のエネルギーを提供します。デュアルコア・エッジの設計では、海水での展開のために、耐腐食性の材料が必要になります。ユニット出力の初期値は20 kWです。保守の損失係数は、海洋にさらされるため、ここが最も高くなっています（0.12）。この部門は、展開できる地点が最も少ない一方で、ユニットあたりの出力は最も高くなっています。

## 6. 計算式

### 設備容量

```
installed_capacity_gw = cumulative_units * average_unit_power_kw / 1,000,000
```

単位：kWからGWへの換算は、10^6で割ります。

### 年間の発電量

```
annual_generation_twh =
    installed_capacity_gw
    * capacity_factor
    * 8760
    / 1000
    * efficiency_factor
    * (1 - maintenance_loss_factor)
    * (1 - grid_integration_loss_factor)
```

- `8760` ＝ 1年の時間数
- `1000`で割ることで、GW·hをTWhに換算します（1 TWh ＝ 1000 GWh のため）
- エネルギー保存則から、`efficiency_factor ≤ 1.0`が必要です
- `capacity_factor ≤ 1.0`は、ユニットが常に定格出力で動くわけではないことを意味します

### 回避された化石燃料電力

```
avoided_fossil_twh = annual_generation_twh * replacement_fraction_of_fossil_energy
```

代替割合は、発電した電力のうち、系統上の化石燃料発電を置き換える割合を表します。再生可能エネルギーが、他の再生可能エネルギーを置き換えたり、系統への接続が限られたりすることがあるため、これが1.0になるとは限りません。

### 回避されたCO2排出量

```
avoided_co2_mt =
    avoided_fossil_twh
    * 1,000,000,000     (TWh to kWh: 1 TWh = 10^9 kWh)
    * fossil_grid_emission_factor_kg_per_kwh
    / 1,000,000,000     (kg to Mt: 1 Mt = 10^9 kg)
```

簡略化すると：`avoided_co2_mt = avoided_fossil_twh * fossil_grid_emission_factor_kg_per_kwh`

### 展開の成長

```
deployment_rate_year_n = deployment_rate_year_0 * (1 + annual_growth_rate)^n
```

累積ユニット数は、際限のない成長を防ぐため、`number_of_sites`で上限を設けています。

### 感度分析

- 設備利用率の感度：発電量の計算式に、CF ± 0.05を適用
- ユニット出力の感度：ユニット出力 × 0.7（低）と × 1.3（高）

## 7. シナリオの説明

### conservative_local_adoption

ゆっくりとした、地域限定のパイロット展開。この技術が小規模では実現可能と示されるものの、広範な普及には規制、資金、製造の障壁がある世界を表します。2050年までに、想定される対象地点の5%に到達します。

**解釈：**期待される貢献は、きわめて小さいものです。このシナリオは下限、すなわち限定的な地域展開が単独で達成しうることを示します。

### moderate_distributed_adoption

25年にわたるプロトタイプの検証の後の、着実な世界的な普及。妥当な政策的支援、オープンハードウェアの複製、水と風のインフラへの段階的な統合を表します。2050年までに、対象地点の20%に到達します。

**解釈：**プロトタイプの検証が成功し、普及が典型的な技術の拡散パターンで拡大する場合の、もっともらしい軌跡です。

### accelerated_open_hardware_adoption

オープンハードウェアの公開が成功した後の、急速な複製。メイカーやNGOによる広範な採用、途上地域での積極的な複製、プロトタイプの検証の成功を想定します。2050年までに、対象地点の50%に到達します。

**解釈：**プロトタイプの成功が必要ですが、まだ実証されていません。現段階では、起こりやすい結果として扱うべきではありません。

### infrastructure_integrated_adoption

世界の水インフラ計画への、深い組み込み。政策上の義務づけ、工学的な標準、協調した製造が必要です。2050年までに、対象地点の80%に到達します。

**解釈：**分散型の回転エネルギー回収が、インフラ設計の標準的な層になる世界を表します。プロトタイプの検証、規制への統合、持続的な投資に強く左右されます。

### unrealistic_upper_bound_check（ストレステスト専用）

**これは予測ではありません。ストレステストです。**

推計されたすべての地点の100%が、最大の速度で展開されます。このシナリオは、2026〜2050年の間では、物理的にも兵站的にも非現実的です。次の目的のために存在します。

- モデルが上限を正しく扱うことを検証する
- エネルギー保存則のガードレールが有効であり続けることを確認する
- 不可能な条件のもとで、理論上の天井がどうなるかを示す

このシナリオを予測や宣伝の主張として用いることは、明確に誤りです。

## 9. 結果の解釈の仕方

### 世界の電力に占める割合

コンソールの表の最後の列は、モデル化した発電量が、世界の電力需要に占める割合を示します。強気のシナリオでも、この割合は小さいままです。理由は次のとおりです。

- モデル化したユニットは、小型の分散型ユニット（0.5〜20 kW）である
- 設備利用率が保守的である
- 世界の電力需要が大きい（約29,000 TWh/年）

これは意図的です。このアーキテクチャの価値は、系統規模の電力の全面的な置き換えではなく、**分散型の補助的エネルギー**にあります。

### 感度分析

CFの感度の列（lo/hi）は、設備利用率が0.05低い、あるいは高い場合の発電量の推計を示します。これは、ユニットが実際にどれだけの頻度で定格出力で動くかについての不確実性を反映します。これらの数値の幅は、結果がその仮定にどれだけ敏感かを示します。

### 回避されたCO2

回避されたCO2の数値は、想定する系統の排出係数（初期値は0.45 kg/kWh）に強く依存します。系統がよりクリーンな地域では、回避される排出量は小さくなります。地域ごとの分析には、このパラメータを地域のデータで更新してください。

### ストレステストのシナリオ

非現実的な上限のシナリオは、見た目には印象的な数値を示しますが、全体を通じて、物理的に非現実的であると明示されています。これらの数値を、期待される結果として引用しないでください。

## 10. 限界

1. **物理的なプロトタイプは存在しません。**すべての効率係数、ユニット出力の値、設備利用率は仮定です。実際の性能は、それより高いことも低いこともありえます。

2. **市場と展開の仮定は推測的です。**対象地点の数、展開の速度、成長率は、不確実性の高い推計です。

3. **系統連系は詳細にはモデル化していません。**現実の系統連系には、蓄電、系統の安定性、需要のプロファイル、出力抑制が伴いますが、ここでは捉えていません。

4. **部門の独立性を仮定しています。**モデルは、部門間の相互作用や、資源をめぐる競合を考慮していません。

5. **製造、材料、コストの分析はありません。**このシミュレーターは、サプライチェーン、原材料の制約、経済的な実現可能性をモデル化していません。

6. **生態系や生態学的な影響のモデル化はありません。**一部の部門（潮汐、灌漑）は、地域の生態系に影響しうる可能性がありますが、モデル化していません。

7. **気候のフィードバックはモデル化していません。**このシミュレーターは、回避されたCO2が気候の軌跡にどう影響するかをモデル化していません。

8. **世界の電力需要を固定しています。**現実には、需要は時間とともに増えます。固定の基準値を使うと、後年の割合を過大に見積もります。

## 11. なぜ分散型の回転エネルギー回収が重要になりうるのか

現在の再生可能エネルギーの開発の多くは、集中型の大規模な設備に焦点を当てています。公益事業規模の太陽光発電所、洋上風力、大規模な水力ダムなどです。これらは有効で必要ですが、**小さく、分散し、持続的な機械的な流れ**という大きな部類のエネルギーを、ほとんど手つかずのまま残しています。

都市の排水、灌漑水路、小河川、沿岸の潮汐、建物の水系統は、合わせると、低出力で絶えず利用できるエネルギーの流れを、膨大な数にわたって構成します。それらはしばしば消費地の近くにあります。大規模な送電インフラを必要としません。地域のマイクログリッドやオフグリッドの用途に適した規模で動作します。

モジュール式で、保守が少なく、低コストの回転式発電機のアーキテクチャが検証できるなら、多数の小型ユニットの総和は、**分散型の補助的エネルギーの層**として意味のあるものになりえます。集中型の電力を置き換えるのではなく、レジリエンスと地域の発電能力を加えるものとして。

デュアルコア・エッジ磁気構造は、そうした発電機モジュールのコストと複雑さを下げうる構想です。それが成功するかどうかは、物理的なプロトタイプの製作と測定に完全にかかっています。

## 12. 現実世界の主張をする前に必要な測定

このシミュレーターの結果を、現実世界の予測として引用できるようになる前に、次のことが物理的な試験で実証されなければなりません。

| 必要な測定 | 必要な理由 |
|---|---|
| 回転数と開放電圧の曲線 | 電磁気モデルを検証する |
| トルクと負荷の曲線 | 機械的な入力パワーの計算を可能にする |
| 定格負荷と部分負荷での効率 | 仮定した効率係数を、実測値に置き換える |
| 持続運転時の熱性能 | 仮定した損失が現実的であることを確認する |
| 水、風、海洋の環境での耐久性 | 保守による損失係数の仮定を検証する |
| 始動トルクと最小の流量のしきい値 | 現実の設備利用率を決める |
| 同程度の大きさの既存の発電機との比較 | デュアルコア設計の貢献を位置づける文脈を提供する |
| 長期的な腐食と付着の挙動（海洋部門） | 展開の寿命に関する仮定を検証する |

これらの測定が存在するまで、**このシミュレーターのすべての数値は例示的なもの**です。

## 13. 政策とインフラへの示唆

プロトタイプの検証が成功すれば、次の政策分野が関わってきます。

- **建築基準：**新しい排水・空調システムへの発電機の組み込みを、義務づけるか、奨励する
- **農業補助金：**灌漑に組み込まれたエネルギー回収を、二重用途のインフラ投資として支援する
- **オープンハードウェアの標準：**分散型のマイクロ発電機のための、測定と安全の標準を確立する
- **系統連系の規則：**非常に小さな分散型発電機（10 kW未満）の連系要件を簡素化する
- **海洋の許認可：**大規模な環境アセスメントを必要としない小型の潮汐ユニットのために、合理化された許可の経路をつくる
- **開発金融：**集中型の系統インフラが限られている低所得地域での、オープンハードウェアの複製に資金を提供する

これらの示唆はいずれも、技術が機能することを前提としていません。プロトタイプの成功を条件としています。
